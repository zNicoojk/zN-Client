# zN Client

Un launcher sencillo para **Minecraft: Java Edition**. Con zN Client puedes iniciar sesión con tu cuenta Microsoft, elegir una versión del juego, ajustar la memoria RAM y abrir Minecraft desde una sola aplicación.

> **Descarga la última versión:** [Ver versiones de zN Client en GitHub Releases](https://github.com/zNicoojk/zN-Client/releases/latest)

## Características

- Inicio de sesión con una cuenta Microsoft que tenga Minecraft: Java Edition.
- Selección entre las versiones disponibles de Minecraft Java.
- Configuración de memoria RAM para el juego.
- Preparación automática del entorno Java que necesite Minecraft.
- Compatibilidad con Fabric y los mods incluidos con zN Client.
- Acceso a las carpetas del juego, mods, mundos, capturas y registros.
- Conservación de las cuentas agregadas para facilitar próximos inicios de sesión. Las credenciales no se guardan como contraseña; la sesión se protege mediante el almacenamiento seguro de Windows.
- Comprobación de actualizaciones del launcher al abrirlo. Cuando haya una nueva versión publicada, zN Client puede avisarte para descargarla e instalarla.

## Descargar e instalar

1. Abre la página de [Releases](https://github.com/zNicoojk/zN-Client/releases/latest).
2. En **Assets**, descarga el archivo `zN-Client-Setup-...exe`.
3. Abre el instalador y sigue las instrucciones en pantalla.
4. Inicia zN Client, agrega tu cuenta Microsoft y elige la versión de Minecraft que quieras jugar.

La primera instalación se descarga desde GitHub Releases. Las próximas actualizaciones del launcher se ofrecerán desde la aplicación cuando estén publicadas.

## Primeros pasos

1. Abre zN Client.
2. Pulsa el botón para agregar o elegir una cuenta e inicia sesión con Microsoft.
3. Selecciona una versión de Minecraft Java.
4. Elige cuánta memoria RAM quieres asignar.
5. Pulsa **Jugar ahora**.

En el primer inicio de una versión, Minecraft puede tardar un poco en descargar los archivos necesarios. El tiempo depende de tu conexión a Internet.

## Actualizaciones

zN Client busca nuevas versiones publicadas en [GitHub Releases](https://github.com/zNicoojk/zN-Client/releases). Si hay una actualización, puedes aceptar la descarga y reiniciar el launcher para instalarla.

Si instalaste una versión muy antigua que no incluía el actualizador, instala primero la versión más reciente desde Releases. Las versiones posteriores podrán actualizarse desde el launcher.

## Privacidad y datos

El launcher necesita conexión a Internet para iniciar sesión, consultar las versiones de Minecraft y descargar los archivos necesarios. Las cuentas se gestionan mediante el flujo de autenticación de Microsoft. zN Client no solicita ni guarda tu contraseña de Microsoft; en Windows, la sesión guardada se protege con el almacenamiento seguro del sistema.

Los ajustes, las cuentas guardadas y los archivos del juego se almacenan localmente en tu equipo, dentro de la carpeta de datos de zN Client. No borres esa carpeta si quieres conservar esos datos.

## Requisitos

- Windows 10 o posterior.
- Conexión a Internet.
- Una cuenta Microsoft con acceso a Minecraft: Java Edition.

El instalador incluye el runtime Java necesario para la versión actual y el launcher puede preparar otros runtimes cuando una versión seleccionada los requiera.
