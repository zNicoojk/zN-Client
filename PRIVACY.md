# Declaracion de privacidad de zN Client

**Ultima actualizacion: 26 de octubre de 2026**

Esta declaracion explica como zN Client, un launcher independiente para Minecraft: Java Edition, trata informacion cuando se utiliza la aplicacion.

## Responsable y contacto

El proyecto zN Client es mantenido por su publicador a traves del repositorio [zNicoojk/zN-Client](https://github.com/zNicoojk/zN-Client). Para consultas sobre privacidad, abre una consulta en [GitHub Issues](https://github.com/zNicoojk/zN-Client/issues). No publiques contraseñas, tokens ni otros datos privados en una consulta.

## Informacion que se guarda en el dispositivo

zN Client guarda localmente la configuracion elegida, como la version de Minecraft y la memoria asignada, y los datos necesarios para recordar las cuentas agregadas, como el nombre y el identificador del perfil de Minecraft. Si eliges guardar una cuenta, el token de renovacion de la sesion se cifra mediante el almacenamiento seguro proporcionado por Windows. La contrasena de Microsoft no se guarda en el launcher.

El launcher tambien guarda en el dispositivo los archivos necesarios para ejecutar Minecraft, incluidos runtimes de Java, mods, mundos, capturas y registros de diagnostico. Los registros de inicio pueden incluir informacion tecnica de la ejecucion, como la version seleccionada y la memoria configurada.

Estos datos permanecen en el equipo y no se envian al mantenedor de zN Client. Desinstalar la aplicacion puede no borrar la carpeta de datos del usuario. Puedes cerrar o quitar cuentas desde el launcher y eliminar manualmente los datos locales si ya no deseas conservarlos.

## Inicio de sesion y servicios de terceros

Para iniciar sesion, zN Client abre el flujo de autenticacion de Microsoft mediante la biblioteca de autenticacion utilizada por la aplicacion. Microsoft procesa la autenticacion y la informacion de la cuenta conforme a sus propias condiciones y declaracion de privacidad. El launcher no recibe ni almacena tu contrasena.

Al usar el launcher, tu dispositivo puede conectarse a servicios de terceros para las funciones solicitadas:

- **Microsoft y Xbox:** autenticacion de la cuenta y acceso al perfil de Minecraft.
- **Mojang/Minecraft:** catalogo de versiones y archivos del juego.
- **Fabric:** metadatos y archivos del cargador y la API Fabric cuando correspondan.
- **Eclipse Adoptium:** descarga de runtimes Java cuando sean necesarios.
- **GitHub:** comprobacion de actualizaciones de zN Client y descarga de sus instaladores desde GitHub Releases.

Estos servicios pueden recibir datos tecnicos de conexion, como la direccion IP, y tratar la informacion de acuerdo con sus propias politicas. zN Client no controla las practicas de privacidad de terceros. Minecraft tambien puede comunicarse con sus propios servicios o con servidores que elijas al jugar.

## Analisis y envio de informacion

zN Client no incorpora una funcion propia para enviar al mantenedor analiticas de uso o registros de diagnostico. Los registros locales no se cargan automaticamente. La comunicacion con los servicios de terceros descritos anteriormente ocurre para prestar las funciones solicitadas por el usuario.

## Menores de edad

El launcher no solicita intencionalmente informacion personal directamente a menores. El inicio de sesion y la elegibilidad para jugar dependen de la cuenta Microsoft y de las reglas aplicables de Microsoft y Minecraft. Si eres padre, madre o tutor y tienes una consulta sobre informacion de una cuenta, contacta al proveedor de esa cuenta.

## Seguridad

El token de renovacion de una cuenta guardada se cifra con el almacenamiento seguro de Windows. Ningun metodo de almacenamiento o transmision puede garantizar seguridad absoluta. Mantén actualizado Windows, protege tu dispositivo y no compartas los archivos de datos del launcher, registros, tokens ni capturas que puedan contener informacion personal.

## Cambios a esta declaracion

Esta declaracion puede actualizarse si cambian las funciones o el tratamiento de datos de zN Client. La version vigente se publicara en este archivo del repositorio.
